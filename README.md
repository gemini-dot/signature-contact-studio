# Signature Contact Studio

Le bleu profond et l'or doux — lance `signature.contact` avec cette palette et commence par la landing et l'éditeur de signature.

Contexte et périmètre convenus (résumé du plan accepté) :

`signature.contact` est un service de création de signatures e-mail, sœur du webmail mails.contact. Le design doit garder l'ADN visuel de mails.Contact (fond crème/ivoire, grandes polices serif avec un mot en italique accentué, cartes blanches arrondies, header avec sélecteur de langue et mode sombre, pied de page avec drapeaux de pays) mais avec une palette distincte : bleu profond / bleu nuit en couleur primaire, accent or doux. Ne pas reprendre le rouge vermillon de Mails.Contact. Logo type « Signature.Contact by Gem's » dans le même esprit que « Mails.Contact by Gem's ». Site principalement en français, avec sélecteur de langue.

Landing page :
- Hero split : à gauche titre fort avec mot en italique or (« Votre signature, votre image » style), à droite un aperçu/de démonstration interactive de signature.
- Sections : la signature vivante (bannière dynamique), le bouton « Prendre rendez-vous » intégré, la carte de visite / QR code, compatibilité Gmail, Outlook, Apple Mail.
- Page tarifs : Gratuit 0 € (1 signature avec mention « signature.contact »), Solo 6 €/mois ou 59 €/an (sans branding, signature vivante, bouton RDV, QR), Équipe 19 €/mois + 1 €/collaborateur/mois (gestion centralisée).
- Pages légales et pied de page avec drapeaux.

Éditeur de signature (cœur de la v1) :
- Formulaire : nom, titre, entreprise, téléphone, e-mail, site web, adresse, réseaux sociaux, logo.
- 4 à 5 modèles de signature, prévisualisation en temps réel.
- Export : code HTML copiable, copie dans le presse-papiers, installation guidée pas à pas pour Gmail, Outlook et Apple Mail.
- Concept de signature vivante : la bannière est une image dynamique hébergée, modifiable depuis un tableau de bord (le dashboard complet peut être une maquette/simple en v1, l'éditeur et la landing sont la priorité).
- Bouton « Prendre rendez-vous » : un lien personnalisable ajouté à la signature.
- Champs uniquement dans l'éditeur pour l'instant : pas de synchronisation Google Workspace/Microsoft 365, pas de statistiques, pas de campagnes.

Design soigné : crème + bleu profond + or doux, serif élégante, cartes arrondies, mode sombre fonctionnel.
